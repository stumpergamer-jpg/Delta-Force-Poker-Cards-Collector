A lightweight, standalone, and feature-complete web tool designed to easily track your progress through the 54 Ahsarah cards in Delta Force.

✨ Key Features Interactive Visual Tracking: Click on any card to instantly toggle its status (green background for Collected, red background for Missing).

Live Statistics & Progress Bar:
Real-time visual progress bar.
Precise counter showing collected cards, missing cards, and overall completion percentage.

Advanced Filters:
By Suit / Type: Quickly isolate ♠ Spades, ♥ Hearts, ♣ Clubs, ♦ Diamonds, or ★ Specials (Jokers & Card Box).
By Status: Filter between all cards, collected only, or missing only to immediately see what you still need to farm.
By Rarity : Ultimate, Legendary, Epic, Rare, Uncommon.

Sorting options : Default, Rarity, Name, Value

Auto-Save: Your collection progress is stored locally in your browser (localStorage), so you never lose your data when closing or refreshing the page.
Import and Export JSON file.

Sleek Gaming UI: Clean, modern dark mode interface optimized for both desktop and mobile screens.
